# Southport Historical Society Brick Finder

Public GitHub Pages Brick Finder for the Southport Historical Society.

## Current indexed Fort Johnston data
- Front Walkway: 536 bricks
- Side Walkway: 178 bricks
- Total: 714 currently indexed Fort Johnston bricks
- Front Walkway photographs: 536

## Site structure
- `index.html` — Find a Brick
- `purchase.html` — Purchase a Brick
- `about.html` — About the Bricks
- `stories.html` — Tell Us About Your Brick

The main Southport Historical Society navigation item links to the Society's primary website.

## Privacy
`bricks.json` contains public locator data only. Do not add purchaser/contact information.

## Branding assets
- `assets/shs-logo.png`
- `assets/fort-johnston.jpg`
- SHS blue: `#000060`

## Brick photos
Verified web-sized brick photos belong in `assets/bricks/`. The `image` field in `bricks.json` points to them.
